# คันจิวิดเจ็ต (Kanji Widget) สำหรับ Android

แอพ Android ที่เพิ่ม widget คันจิบนหน้าจอหลัก แสดง:
- ตัวคันจิ (ตัวใหญ่)
- คำอ่าน คุน / อง
- ความหมายภาษาไทย
- คำศัพท์ตัวอย่าง + คำอ่าน + คำแปล
- ประโยคตัวอย่าง + คำอ่านฮิรางานะ + คำแปลภาษาไทย

มีคันจิระดับ N5 จำนวน 100 ตัว · เปลี่ยนเองวันละตัว (หรือทุกชั่วโมง) · แตะตัวคันจิใน widget เพื่อดูตัวถัดไป ·
เลือกพื้นหลังแบบโปร่งใสให้ตัวหนังสือลอยบนวอลเปเปอร์ได้

---

## วิธีได้ไฟล์ APK

### วิธี A: ให้ GitHub build ให้ (ไม่ต้องลงโปรแกรม)
repo นี้ตั้งค่าไว้แล้ว ทุกครั้งที่มีการแก้ไฟล์ GitHub จะ build APK ให้อัตโนมัติ
1. ไปที่แท็บ **Actions** → รอ "Build APK" ขึ้นเครื่องหมาย ✅ (ประมาณ 3–5 นาที)
2. กดเข้าไปที่งานล่าสุด → เลื่อนลงไปที่ **Artifacts** → ดาวน์โหลด `KanjiWidget-apk`
3. แตกไฟล์ zip จะได้ `app-debug.apk` → เปิดบนมือถือเพื่อติดตั้ง (อนุญาต "ติดตั้งแอพที่ไม่รู้จัก")

### วิธี B: Android Studio
เปิดโฟลเดอร์นี้ใน Android Studio (Gradle 8.9 ขึ้นไป) → กด ▶ Run หรือ Build → Build APK(s)

---

## เพิ่มคันจิเอง
แก้ไฟล์ `app/src/main/assets/kanji.txt` — หนึ่งบรรทัดต่อหนึ่งตัว คั่นแต่ละช่องด้วย `|` เรียงตามนี้:

`คันจิ|อง|คุน|ความหมาย|คำศัพท์|คำอ่านคำศัพท์|คำแปลคำศัพท์|ประโยค|คำอ่านประโยค|คำแปลประโยค`

ตัวอย่าง:
`人|ジン・ニン|ひと|คน|日本人|にほんじん|คนญี่ปุ่น|あの人は日本人です。|あのひとはにほんじんです。|คนคนนั้นเป็นคนญี่ปุ่น`

แก้ไฟล์บน GitHub แล้วกด Commit ระบบจะ build APK ใหม่ให้อัตโนมัติ

## หมายเหตุเรื่องหน้าจอล็อก
widget นี้วางบน **หน้าจอหลัก** ได้ทุกเครื่อง
หน้าจอล็อกของ Samsung (One UI) ส่วนใหญ่อนุญาตเฉพาะ widget ของระบบ จึงอาจวางบนหน้าจอล็อกไม่ได้ ขึ้นอยู่กับรุ่นและเวอร์ชัน
